# vsemvamdam-Steam-Helper

Расширение для Steam: цены с разных площадок прямо в инвентаре, float и наклейки, массовая продажа, улучшенный маркет и трейды. Работает в Chrome, Edge, Яндекс Браузере, Opera и других браузерах на Chromium (версия 111+).

## Установка

1. Скачайте `vsemvamdam-Steam-Helper-<версия>.zip` из [Releases](../../releases) или из артефактов последней сборки во вкладке **Actions**.
2. Распакуйте архив в постоянную папку (её нельзя удалять — браузер грузит расширение оттуда).
3. Откройте `chrome://extensions` (в Яндексе — `browser://extensions`), включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное** и выберите папку с `manifest.json`.
5. Войдите в Steam в этом браузере — и откройте свой инвентарь.

Обновление: распакуйте новую версию в ту же папку и нажмите ⟳ у расширения на `chrome://extensions`.

## Что умеет

**Инвентарь**
- цена на каждой карточке и общая стоимость инвентаря (Steam или любая площадка на выбор);
- float с точностью до 12 знаков, износ, паттерн, paint index, диапазон float скина, фазы Doppler / Gamma Doppler;
- наклейки и брелоки с потёртостью и ценой каждой, сумма наклеек;
- таймер трейдлока и защиты обмена;
- сравнение цен на 9 площадках со ссылками и разницей к Steam;
- сортировка по цене, float, названию, наклейкам, доступности;
- режим выбора (клик, Shift+клик, «все видимые», «такие же»);
- **быстрая продажа**: дешевле минимума, по медиане, по лучшей заявке, своя цена — с пересчётом «вы получите»;
- **массовая продажа** сотен предметов с выбором стратегии цены, ручной правкой и журналом;
- таблица-менеджер всего инвентаря с фильтрами и экспортом в CSV.

**Маркет**
- цены площадок, минимум, медиана, объём, лучшая заявка и спред;
- калькулятор комиссии Steam и профита «купить там — продать тут»;
- float, паттерн, фаза и наклейки с ценами у каждого лота, сортировка лотов по float, цене, наклейкам;
- 10–100 лотов на странице, кнопка «Быстро» — покупка без окна Steam (с подтверждением, отключается);
- мои лоты: суммы, фильтр, массовое снятие, проверка «перебили ли мой лот»; сумма заявок;
- экспорт истории маркета в CSV.

**Трейды**
- в окне обмена — цены на предметах, суммы обеих сторон и итог;
- в списке офферов — оценка каждого оффера, принять / отклонить в один клик, сортировка по выгоде, «принять все подарки»;
- фоновые уведомления о новых офферах с оценкой стоимости и счётчик на значке.

**Ещё**
- попап: поиск предмета и сравнение цен, входящие офферы, быстрые ссылки;
- профиль: SteamID64 / SteamID3, ссылки на csstats, Leetify, FACEIT, SteamDB, стоимость CS2-инвентаря;
- магазин: цены игры в разных регионах в одной валюте;
- валюта кошелька или любая другая, светлая/тёмная тема настроек.

## Откуда данные

| Что | Источник |
|---|---|
| Float, паттерн, наклейки | inspect-данные самого Steam (с марта 2026 они лежат прямо в ссылке) — декодируются локально, без ботов |
| Цены Steam | маркет Steam через вашу сессию (с очередью — Steam ограничивает частоту) |
| Skinport, Market.CSGO, LIS-SKINS, Waxpeer | публичные выгрузки цен площадок, кэш 20–30 минут |
| DMarket | публичный API по запросу |
| CSFloat | по вашему API-ключу (настройки → Площадки) |
| BUFF163, YouPin | только ссылки: их цены доступны после входа на сайт |
| Курсы валют | open.er-api.com, запасной — fawazahmed0/currency-api |
| Названия наклеек и брелоков | [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API) (MIT), обновление — `npm run data` |

Расширение не отправляет данные на свои серверы: всё хранится в браузере, ключ CSFloat — только локально.

## Ограничения

- Подтверждения лотов и обменов в мобильном приложении Steam не автоматизированы — Steam попросит подтвердить их как обычно.
- Точные цены Steam грузятся по очереди (примерно 1 предмет в 3 секунды), до этого показывается оценка со знаком ≈.
- Если Steam поменяет вёрстку, отдельные блоки могут временно пропасть — пишите, поправлю.

## Разработка

```bash
npm test          # юнит-тесты: декодер inspect, комиссии, валюты
npm run e2e       # сквозной тест: расширение в Chrome + страницы-фикстуры Steam
npm run data      # обновить справочники наклеек/брелоков/скинов
npm run build     # собрать dist/vsemvamdam-Steam-Helper-<версия>.zip
```

Структура: `src/background` — фоновый воркер (цены, очередь Steam, трейды), `src/content` — скрипты страниц Steam (`bridge.js` читает данные страницы, `core.js` — общее ядро, остальные — по разделам), `src/shared` — общий код (декодер inspect, комиссии, валюты, настройки), `src/popup`, `src/options` — интерфейс.

Сборка zip и релиз делаются GitHub Actions: пуш в `main` — артефакт, тег `v*` — релиз.
